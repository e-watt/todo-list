# Todo list

This is a todo list that I made while doing The Odin Project Full Stack Javascript path, Javascript course.

## Manual install

Manual install is using the dev server and opening http://localhost:8080/ in your browser. This guide is for linux users, but windows and macOS install should be pretty similar.

To manually install this todo list, you need to have node.js and npm installed.
You have to clone the repository. Run npm install in your terminal. This will download all dependencies. To start the dev server run npm start in your terminal. This should open http://localhost:8080/ in your browser, but if it doesn't then open it manually.

### Cloning the repository
---------------------------

This has different methods. The one shown here will require having an SSH key connected to your github account and having set up git.

Run in a suitable directory:

    git clone git@github.com:e-watt/todo-list.git
    
### Installing dependencies
----------------------------

Run:

    npm install

### Starting the dev server
----------------------------

Run:

    npm start

and open http://localhost:8080/ if it isn't already open.
